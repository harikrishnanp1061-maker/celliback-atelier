# Celliback Atelier 🎀
> **Playful 3D forms meet 10ft protective armor.**  
> An editorial luxury D2C e-commerce experience for tactile, matte ceramic & sculpted phone cases.

![Celliback Atelier](https://images.unsplash.com/photo-1586105251261-72a756497a11?auto=format&fit=crop&w=1200&q=80)

---

## ✨ Features & Architecture

- **Interactive 3D Phone Elevation**: Fanned deck of handcrafted collector editions (Cloud Bunny Hop Flagship, Strawberry Milk Edition, Boba Bear Hug Edition) with authentic cutout packshots, 10ft drop certified badges, and multi-layered depth shadows.
- **Touch-Optimized Mobile Interaction**:
  - Drag and scrub fingers across the 3 hero phones on iOS Safari & Android Chrome with real-time geometric proximity detection.
  - Phones rise up smoothly by >50px, scale up, un-tilt, and highlight their frosted ceramic inspect capsules.
  - 1-tap mobile edition switcher chips for instant selection on smaller screens.
- **Scroll-Linked Satin Ribbon & Coquette Bow**:
  - Full-page background satin ribbon with dynamic S-curve geometry wandering diagonally behind sections.
  - Hardware-accelerated Framer Motion integration tied to scroll progress.
  - Bespoke French coquette satin bow at the traveling tip following path angles.
- **Tactile Sound Engine (Web Audio API)**:
  - Lo-fi ambient pentatonic melody with visualizer equalizer in the navbar.
  - Organic bubble pop sound on taps and card elevations.
  - Magical chime and champagne confetti burst on cart interactions.
- **Atmospheric Sectional Theming & Textures**:
  - *Hero*: Warm Linen Canvas & Ambient Petal Glow (`#FAF4ED` / `#FDF2F4`)
  - *Collection*: Textured Rose Sandstone with pinstripe weave (`#F4ECE3`)
  - *Armor Engineering*: Technical Porcelain Ceramic with dot matrix (`#F9F7F4`)
  - *In The Wild*: Dusty Petal Rose with ribbon weave (`#F8EDEF`)
  - *Store Locator*: Architectural Taupe-Sandstone with WGS-84 vector cartography (`#EBE2D5`)
  - *Unboxing Ceremony*: Festive Silk Blush with keepsake drawer casket (`#FAF0F2`)
  - *Concierge Desk*: Chamois Linen with VIP response form (`#F4ECE3`)
  - *Footer*: Deep Velvet Ink Charcoal & Rose-Cocoa (`#201A1C`)
- **Interactive Customizer & Cart Drawer**:
  - Device model selector (iPhone 16 Pro Max down to iPhone 13).
  - Hue swatch selector and material spec anatomy breakdown.
  - Slide-out cart drawer with free worldwide shipping meter.

## 🛠 Tech Stack

- **Framework**: [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Build Tool**: [Vite 8](https://vitejs.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Animation**: [Framer Motion](https://www.framer.com/motion/)
- **Audio**: Custom Web Audio API synthesizer engine
- **Icons**: [Lucide React](https://lucide.dev/)
- **Celebration Effects**: `canvas-confetti`

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v18 or newer)
- `npm` or `pnpm`

### Installation
```bash
# Clone the repository
git clone https://github.com/harikrishnanp1061-maker/celliback-atelier.git

# Navigate into the project directory
cd celliback-atelier

# Install dependencies
npm install
```

### Development
```bash
# Start the local development server with network exposure
npm run dev -- --host
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### Production Build
```bash
# Compile TypeScript and bundle for production
npm run build

# Preview the production build locally
npm run preview
```
